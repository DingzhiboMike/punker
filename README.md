# punker

Скилл для Claude.

Вживляет характер в готовый текст, не переписывая его: находит места, где автор струсил, вставляет точную деталь, позицию с аргументом и концовку, которая продолжает думаться. Референсы: Довлатов, Буковски, Троицкий, Чехов, Ильяхов, Руденко.

## Когда использовать

- Текст грамотный, но мёртвый
- Слишком гладко и безопасно
- Нужно поднять градус и добавить вызов

Не подходит для написания текста с нуля (author-in-residence) и чистки AI-следов (humanizer).

## Установка

**Claude Code.** Склонируйте репозиторий в папку скиллов:

```bash
git clone https://github.com/DingzhiboMike/punker.git ~/.claude/skills/punker
```

**Claude.ai / десктоп-приложение.** Скачайте репозиторий как ZIP (Code → Download ZIP) и загрузите его в настройках Claude, в разделе со скиллами.

После установки скилл включается сам, когда запрос подходит под его описание. Можно вызвать и явно — по имени `punker`.
